Instalar no telemóvel

Quando estiver alojado num endereço HTTPS, abre o site no navegador do telemóvel e escolhe “Adicionar ao ecrã principal”.

⇄

Sincronização online

Neste momento, os dados estão guardados neste navegador. Para sincronizar computador e telemóvel, é necessário configurar uma base de dados online.

A configuração, por si só, não cria uma base de dados nem autenticação. Consulta o README incluído no projeto antes de ativar a sincronização. Nunca coloques uma chave secreta/service_role no navegador.

Como os teus dados são guardados

Sem sincronização configurada, os dados ficam no armazenamento local deste navegador. Exporta uma cópia regularmente e importa-a noutro dispositivo se precisares de transferir os teus dados manualmente.
